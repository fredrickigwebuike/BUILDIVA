# BUILDIVA — Stage 02: Firebase Foundation

Stage 02 is cumulative: it contains the Stage 01 website plus the Firebase foundation.

Included:
- Firebase Web SDK dependency
- Environment configuration template
- Firebase initialization for Auth, Firestore and Storage
- Email/password customer registration/login functions
- Firestore data-access foundation
- Production-oriented Firestore rules
- Storage rules
- Firestore indexes
- Firebase Emulator Suite configuration
- Database architecture documentation
- Security guidance
- Placeholder server-side/functions area

## What is NOT included

There is no real Firebase project configuration or secret credential in this package. That must be connected to the actual BUILDIVA Firebase project.

## Next stage

Stage 03 will build the real customer account system on top of this foundation:
registration, login, password recovery, profiles, addresses, account dashboard and protected customer data.
